# Backpropagation From Scratch

## Overview
This project is my implementation of a feed-forward Neural Network that specifically aims to 
be able to classify images of digits 0-9.

## Features
- **Custom matrix library** No external matrix libraries were used in this project.
- **Model reading and writing** Capable of reading and writing model files for portability.
- **Test individual images** A Network Runner is provided for viewing network information and testing individual images.

## Requirements
### Software
- C++ compiler (supporting C++20 or later)

### Hardware
- As strong a computer as you can manage

## Installation
1. **Clone the Repository**
   ```bash
   git clone git@github.com:KyNgo2002/KNN.git
   cd KNN
   ```
